# Time Series Forecasting

Practice project for time series analysis and forecasting using statistical and ML approaches.

## Project Structure

```
src/                - Source code
data/               - Sample time series data
tests/              - Unit tests
```

## Methods

- ARIMA / SARIMA (statsmodels)
- Exponential Smoothing (Holt-Winters)
- Linear Regression with lag features
- Random Forest with lag features
- Moving Average Baseline
- Train/Test temporal split

## Evaluation

RMSE, MAE, MAPE across methods with baseline comparison.
